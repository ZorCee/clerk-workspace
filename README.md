# 文事台 · 湖南谛图科技有限公司

谛图科技内部使用的小型文员工作台。台账写在 **D:\谛图文事台数据**，不放 C 盘，清浏览器也不会丢。同时会留一份 `wenshi.bak.json` 备份。

## 能做什么

- **合同统计**：单章合同、电子合同
- **发票统计**：进项 / 销项、价税合计
- **应收应付**：未收未付
- **物品清单、纸质文件存档位置**
- **报价单开具、普通合同套打**
- **工作交接清单**
- **资料库**：承接飞书云盘，文件落在 D 盘，可检索、打开、建夹
- 各表可检索、增改删，导出 CSV 用 Excel / WPS 打开

发出和归档仍由人确认。系统只起草、登记、提醒。台账和文件都在本机，用来逐步替代飞书办公里的云盘和合同表。

## 开启 / 关闭

第一次先在本目录执行一次 `npm install`。

| 做什么 | 双击文件 | 或命令 |
|---|---|---|
| 本机开启 | `启动网站.bat` | `npm start` |
| 给领导同事演示 | `启动演示.bat` | `npm run demo` |
| 给外地临时访问 | `开启外地访问.bat` | `npm run share` |
| 关闭网站和外地通道 | `关闭网站.bat` | `npm run stop` |

本机打开 http://localhost:5173/ 。外地访问时，把终端里出现的 `https://xxxx.loca.lt` 发给对方。关掉窗口或运行关闭脚本后，外地链接立刻失效。也可以在运行中的窗口按 `Ctrl+C`。

数据文件：`D:\谛图文事台数据\wenshi.json`。飞书云盘迁入的文件在 `D:\谛图文事台数据\资料库`。侧栏可点「打开D盘数据夹」。

## 演示

给别人看功能时，双击 **`启动演示.bat`**，打开 http://localhost:5175/ 。

- 用的是虚构合同、发票、资料库文件夹，页顶会标「演示数据」
- 数据在 `D:\谛图文事台数据-演示`，**不会改正式台账**
- 首页有「演示怎么讲」，按步骤点进去即可
- 讲完后侧栏可「重新装入演示数据」；`关闭网站.bat` 会把演示（5175）一并关掉
- 正式环境和演示可以同时开

## 从飞书把文件搬过来

1. 飞书云盘里选文件或文件夹，下载到电脑（文件夹一般是 zip）。
2. 打开文事台 → **资料库**，拖进去或点「导入飞书压缩包」。
3. 飞书在线文档要先「下载为 Word / Excel / PDF」，再上传。

合同台账仍用「飞书合同导入」。资料库管文件，合同表管登记。

完整操作说明见 **`演示/文事台使用说明书.html`**（也可打开同名 `.md`），章节与演示视频一致。
