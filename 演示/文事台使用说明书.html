文事台使用说明书

对照演示视频《文事台完整功能演示》编写。系统只起草、登记、提醒，不代替盖章外发。

1. 这是什么

文事台把飞书里的云盘文件夹和合同台账收到本机，给办公室文员日常使用。

做不做
登记合同、发票、应收应付聊天、日程、审批
管本机资料库、检索、打开文件在线多人同时改文档
起草报价单、套打合同书盖章、对外发送
提醒待开票、未付、交接未完代替人确认发出和归档

台账和文件在 D:\谛图文事台数据，不放 C 盘。清浏览器也不会丢。每次保存前会留 wenshi.bak.json。

对应视频开场。

2. 怎么开、怎么关

第一次先在本软件目录执行一次 npm install。

做什么双击地址
日常使用启动网站.bathttp://localhost:5173/
给别人看演示（虚构数据）启动演示.bathttp://localhost:5175/
给外地临时看开启外地访问.bat终端里的 loca.lt 链接
关闭关闭网站.bat或窗口里 Ctrl+C

侧栏「打开D盘数据夹」打开数据目录；「打开附件夹」打开合同扫描件目录。

3. 今日工作台

文员每天从这里开工。四个数从台账算出，不用另做待办表。

数字含义
待办任务还没处理完的开票、未开、交接
合同份数单章 + 电子合同条数
合同未开两张合同表「未开」列合计
合同未付两张合同表「未付」列合计

我的任务从台账长出来：发票号码为空 / 待开 / 待定 → 待开发票；合同未开大于 0 → 合同未开；交接「文档完成情况」不是 √ → 交接未完。

点名称跳到台账。处理完点已完成（交接会打勾），或取消，之后还能放回待办。往下「合同按年」点数字进入该年采购或销售。

对应视频第 1 段。

4. 单章合同、电子合同

和飞书多维表一样：左侧按年、按采购/销售，格子里直接改，约半秒写入 D 盘。

怎么看

  1. 侧栏「合同 → 单章合同统计」，或工作台点某年数字。
  2. 左侧选全部，或某年 → 采购 / 销售。
  3. 上方可搜名称、相对方、金额，例如「临港」。
  4. 点「电子合同」换表。两套分开统计、分开导入。

怎么改

金额、已开未开、已付未付、状态、相对方都在格子里改。「已开 + 未开」「已付 + 未付」应等于合同金额。系统会按金额轧差，也可以手改未开、未付。

「合同」列填附件文件名，须与 D:\谛图文事台数据\附件 里的文件名一致才能打开扫描件。电子合同用「纸质版位置」记柜层。

对应视频第 2 段。

5. 从飞书导入合同

  1. 飞书多维表导出 Excel，或复制表头加数据行。
  2. 打开「飞书合同导入」。单章和电子分开导，不要混在一张里。
  3. 拖入文件或粘贴识别，核年度、采购/销售后写入。重复行会跳过。

资料库不管合同数字，只管文件。对应视频第 3 段。

6. 资料库

路径：D:\谛图文事台数据\资料库。目录对齐飞书：财务、公司基础、合同、申报、项目、招投标。

搬文件

  1. 飞书下载文件或 zip。
  2. 拖进资料库，或「上传文件 / 上传文件夹 / 导入飞书压缩包」。
  3. 大文件夹请点「打开资料库文件夹」，用资源管理器复制。网页若提示 Failed to fetch，改用这个办法，或一次少选几个。

在线文档用链接

飞书文档 / 表格 / 多维表格不是文件。打开后复制浏览器地址，在文件夹里「添加链接」。点名称用浏览器打开。招投标下那些在线表都按此办理。

还可搜索、建夹、重命名、删除、本机打开。「收入合同附件」会把附件夹复制一份到资料库「合同附件」。

对应视频第 4 段。

7. 发票统计

财务资料 → 发票统计。可从合同带出相对方和未开金额。没拿到票号就写「待开」或空着，会回到今日工作台。可导入 Excel、导出 CSV。

对应视频第 5 段前半。演示里常见待开：客户乙 8000、临港二期 27000。

8. 应收应付

财务资料 → 应收应付明细。应收账款是别人欠我们；应付是我们欠别人；预付如投标保证金。余额要和合同未开、未付对上。

对应视频第 5 段后半。

9. 物品、存档、交接

在「公司基础资料」下。

  • 物品清单：位置 + 名称，如大厅货架几层放什么。
  • 纸质文件存档：柜层与资料，对应合同「纸质版位置」。
  • 工作交接清单：完成情况不是 √，今日待办会出现「交接未完」。交完点已完成或改成 √。

对应视频第 6 段。

10. 报价单

  1. 工作台点「开具报价单」。
  2. 左边填项目和物料，右边即时预览。含税合计跟数量、单价走。
  3. 复制正文或下载 Word，再写入台账。

可以空着或写待定。Word 发出前仍由人确认。系统不外发。

对应视频第 7 段前半。

11. 普通合同模板

合同 → 普通合同模板。供方默认本公司，填需方、货物、数量后套打。写入进单章合同。电子签走电子合同表。系统不盖章、不自动发送。

对应视频第 7 段后半。

12. 备份、演示与清空

按钮作用
导出 / 导入备份JSON 备份。导入会覆盖当前台账
重新装入演示数据恢复虚构演示。真合同会被覆盖，导入飞书前慎用
清空数据清空台账。资料库要用资料库页的「清空资料库」

页顶黄条表示当前是演示台账。演示环境（5175）数据在 D:\谛图文事台数据-演示，不改正式目录。

13. 日常建议

  1. 先看今日工作台待办。
  2. 新合同：导入或格子里加一行；扫描件放附件夹，文件名与「合同」列一致。
  3. 开票登记；没号写待开。
  4. 收付款后改已付/未付，核对应收应付。
  5. 找文件走资料库；飞书在线文档用链接。
  6. 报价、合同书：套打 → 下 Word → 人确认后再发。
  7. 交接改完成情况，待办会消失。

14. 常见问题

上传 Failed to fetch，是不是太大？ 多半是浏览器掐断了。请用资源管理器复制进资料库，或打 zip，或一次少选几个。

飞书文档上传是空的？ 在线文档请「添加链接」。要留底再下载为 Word / Excel / PDF 后上传。

改了格子刷新没了？ 看清是 5173 正式还是 5175 演示。

能不能代替飞书？ 云盘和合同表可以逐步转过来。聊天、日程、审批、在线多人编辑，文事台不做。
