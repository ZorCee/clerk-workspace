# 文事台使用说明书

湖南谛图科技有限公司 · 内部文员工作台  
对照演示视频《文事台完整功能演示》编写

---

## 1. 这是什么

文事台给办公室文员用，把飞书里的**云盘文件夹**和**合同台账**收到本机。

| 做 | 不做 |
|---|---|
| 登记合同、发票、应收应付 | 聊天、日程、审批 |
| 管本机资料库、检索、打开文件 | 在线多人同时改文档 |
| 起草报价单、套打合同书 | 盖章、对外发送 |
| 提醒待开票、未付、交接未完 | 代替人确认发出和归档 |

系统只**起草、登记、提醒**。盖章和外发仍由人确认。

台账和文件在 **D:\谛图文事台数据**，不放 C 盘。清浏览器也不会丢。每次保存前会留一份 `wenshi.bak.json`。

对应视频：开场「这是湖南谛图科技的文员工作台。用来登合同、管资料库、看发票和收付。」

## 2. 怎么开、怎么关

第一次使用，先在本软件目录执行一次 `npm install`。

| 做什么 | 双击 | 打开地址 |
|---|---|---|
| 日常使用 | `启动网站.bat` | http://localhost:5173/ |
| 给别人看演示（虚构数据） | `启动演示.bat` | http://localhost:5175/ |
| 给外地临时看 | `开启外地访问.bat` | 终端里出现的 `https://xxxx.loca.lt` |
| 关闭 | `关闭网站.bat` | — |

也可以在黑色窗口里按 `Ctrl+C`。外地链接关掉后立刻失效。

侧栏「打开D盘数据夹」会打开 `D:\谛图文事台数据`。「打开附件夹」打开合同扫描件所在目录。

对应视频结尾：「双击启动网站.bat，打开 http://localhost:5173/。」

## 3. 今日工作台

文员每天从这里开工。四个数都从台账算出来，不用另做一张待办表。

| 数字 | 含义 |
|---|---|
| 待办任务 | 还没处理完的开票、未开、交接 |
| 合同份数 | 单章 + 电子合同条数 |
| 合同未开 | 两张合同表「未开」列合计 |
| 合同未付 | 两张合同表「未付」列合计 |

**我的任务**从台账长出来：

- **待开发票**：发票号码是空的、待开或待定
- **合同未开**：合同「未开」大于 0
- **交接未完**：交接清单里「文档完成情况」不是 √

点任务名称，跳到对应台账。处理完点 **已完成**（交接会自动打勾）；也可以 **取消**，之后还能「放回待办」。

往下是 **合同按年**：单章、电子分开。点某年的「采购」或「销售」数字，进入那一张多维表。

对应视频第 1 段。

## 4. 单章合同、电子合同

和飞书多维表同一套用法：左侧按年、按采购/销售打开，格子里直接改。

### 4.1 怎么看

1. 侧栏 **合同 → 单章合同统计**，或工作台点某年数字。
2. 左侧选「全部单章合同」，或某年 → 采购 / 销售。
3. 上方可搜合同名称、相对方、金额。例如搜「临港」，只留这一家。
4. 点标签 **电子合同**，换到电子签那一张。两套表分开统计、分开导入。

### 4.2 怎么改

金额、已开、未开、已付、未付、状态、相对方，都在格子里改，不用弹窗。改完约半秒写入 D 盘。

「已开 + 未开」应等于合同金额，「已付 + 未付」也应相等。系统会按金额自动轧差；你也可以手改未开、未付。

### 4.3 字段说明（两张表相同）

合同项目名称、类型、相对方、签订时间、合同金额、状态、已开、未开、开票时间、发票号码、已付、未付、合同（附件文件名）、纸质版位置、备注、归档年度、采购与销售。

电子合同多记柜层一类「纸质版位置」。附件文件名要和 `D:\谛图文事台数据\附件` 里的文件名一致，才能点开扫描件。

对应视频第 2 段。

## 5. 从飞书导入合同

侧栏 **合同 → 飞书合同导入**，或工作台「导入单章合同 / 导入电子合同」。

1. 在飞书多维表导出 Excel，或复制表头加数据行。
2. **单章**和**电子**分开导，不要混在一张里。
3. 把文件拖进页面，或粘贴后识别。
4. 核对年度、采购/销售，再写入。已有的重复行会跳过。

导入后到对应合同表里按年检查。资料库不管合同数字，只管文件。

对应视频第 3 段。

## 6. 资料库（替代飞书云盘）

文件在 **D:\谛图文事台数据\资料库**。左侧目录按飞书习惯：财务资料、公司基础资料、合同、申报资料、项目资料、招投标资料。

### 6.1 把飞书文件搬进来

1. 飞书云盘下载文件或文件夹（文件夹一般是 zip）。
2. 打开对应资料库文件夹，拖进去；或点「上传文件 / 上传文件夹 / 导入飞书压缩包」。
3. **大文件夹**请点「打开资料库文件夹」，用资源管理器直接复制，比网页上传稳。网页上传会分片；若出现「Failed to fetch」，改用资源管理器复制，或一次少选几个。
4. zip 会先传到「飞书迁入」再解压。

飞书里还在同步、本机读出来是空的文件，不要传。请先下载到电脑。

### 6.2 在线文档是链接，不是文件

飞书文档、表格、多维表格没有实体文件。不要上传占位空文件。

1. 在飞书里打开该文档，复制浏览器地址栏。
2. 在对应文件夹点 **添加链接**。
3. 名称写清楚，网址以 http:// 或 https:// 开头。
4. 点名称会用浏览器打开。

招投标资料下面那些在线表，都按这个办法放。

### 6.3 日常

- 搜索框按文件名找。
- 可新建文件夹、重命名、删除、用本机打开。
- 「收入合同附件」会把附件夹里的扫描件复制一份到资料库「合同附件」，原件还在。

对应视频第 4 段。

## 7. 发票统计

侧栏 **财务资料 → 发票统计**。

- 可以从合同带出相对方和未开金额。
- 还没拿到票号，发票号码写成 **待开** 或空着。这类会回到今日工作台。
- 已登记且不是「待开」的，计入「已登发票金额」。
- 可导入 Excel、导出 CSV，附件仍放在 `D:\谛图文事台数据\附件`。

演示数据里常见待开：客户乙 8000、临港建设二期 27000。正式使用时按真合同登记。

对应视频第 5 段前半。

## 8. 应收应付

侧栏 **财务资料 → 应收应付明细**。

| 类别 | 含义（口诀） |
|---|---|
| 应收账款 | 别人欠我们的 |
| 应付账款 | 我们欠别人的 |
| 预付账款 | 先付出去的（如投标保证金） |
| 应收票据 / 其他应收 / 其他应付 | 按财务原表分块 |

余额应和合同「未开」「未付」对得上。演示里：临港尾款、青禾到票未付、投标保证金。

对应视频第 5 段后半。

---

## 9. 物品、存档、交接

侧栏 **公司基础资料** 下三张表。

**物品清单**  
存放位置 + 物品名称。例如大厅货架 1F 打印纸、2F 文具。找东西不用问人。

**纸质文件存档**  
左柜右柜哪一层放合同、招标文件、财务凭证。和合同表「纸质版位置」对应。

**工作交接清单**  
模块、事项、移交资料、物品、进度、交接文档、文档完成情况。  
完成情况不是 √，今日工作台会出现「交接未完」。交完在待办点已完成，或在本表改成 √。

对应视频第 6 段。

## 10. 报价单

工作台点 **开具报价单**，或 财务资料 → 报价单 再开具。

1. 左边填项目名称、日期、物料、单位、数量、含税单价。
2. 右边即时预览「产品报价单」。含税合计跟数量、单价走。
3. 可 **复制正文** 或 **下载 Word**。
4. **写入台账** 后进入报价单列表。

各项可以空着或写待定。下载 Word 后仍由人确认再发给对方。系统不外发。

对应视频第 7 段前半。

---

## 11. 普通合同模板

侧栏 **合同 → 普通合同模板**。

1. 供方默认本公司，填需方、合同号、货物、数量、单价等。
2. 右边是合同书套打预览。
3. 复制正文或下载 Word，再 **写入台账**，会记进**单章合同**（履约中、销售）。

电子签合同走「电子合同」那张表，不要用这张模板代替。  
系统**不会盖章**，也不会自动发送。

对应视频第 7 段后半。

## 12. 备份、演示与清空

侧栏底部：

| 按钮 | 作用 |
|---|---|
| 导出备份 | 下载当前台账 JSON |
| 导入备份 | 用以前导出的 JSON 覆盖当前台账（先确认） |
| 重新装入演示数据 | 恢复虚构演示台账。正式真合同会被覆盖，导入飞书前慎用 |
| 清空数据 | 清空台账各表，资料库要用资料库页的「清空资料库」 |

页顶若出现黄条「当前是演示台账」，说明正在看虚构数据。导入飞书真合同后可以清空再导入。

演示环境（5175）的数据在 `D:\谛图文事台数据-演示`，**不会改**正式目录。

对应视频结尾「重新装入演示数据」。

## 13. 日常建议怎么走

1. 打开文事台，先看今日工作台待办。
2. 新签合同：飞书导入或格子里加一行；扫描件放附件夹，文件名与「合同」列一致。
3. 开票：在发票统计登记；未拿到号就写待开。
4. 收款付款后，改合同已付/未付，并核对应收应付。
5. 找文件走资料库；飞书在线文档用链接。
6. 对外报价、合同书：套打 → 下 Word → 人确认后再发。
7. 交接：改完成情况，待办会跟着消失。

## 14. 常见问题

**上传出现 Failed to fetch，是不是文件太大？**  
多半是浏览器把一次过大的上传掐断了。请用「打开资料库文件夹」在资源管理器里复制，或打成 zip 再导入，或一次少选几个。

**飞书文档上传后是空的？**  
在线文档不是文件。复制浏览器地址，用「添加链接」。需要留底再在飞书里下载为 Word / Excel / PDF 后上传。

**改了格子刷新没了？**  
数据在 D 盘。确认开的是 http://localhost:5173/（正式）还是 5175（演示）。不要开错环境。

**删除文件夹后又出现了？**  
旧版会自动重建种子文件夹，现已改为只建资料库根目录。请用当前版本，并重启过 `启动网站.bat`。

**能不能代替飞书？**  
云盘和合同表可以逐步转到文事台。聊天、日程、审批、在线多人编辑，文事台不做。
